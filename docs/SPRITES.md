# Stick-Gotchi Sprite Export Checklist

Workflow: Aseprite → PNG+JSON → `tools/spr2c.py` → C header in `src/generated/`.

---

## 1. Aseprite Setup

### Canvas sizes (exact — do not scale in Aseprite)

| Stage   | Size    | Scale | Display px |
|---------|---------|-------|------------|
| Egg     | 12 × 14 | 3×    | 36 × 42    |
| Baby    | 16 × 16 | 3×    | 48 × 48    |
| Young   | 20 × 22 | 2×    | 40 × 44    |
| Adult   | 24 × 26 | 2×    | 48 × 52    |
| Emote   |  8 ×  8 | 2×    | 16 × 16    |
| Action  |  8 ×  8 | 2×    | 16 × 16    |
| HUD     |  6 ×  6 | 1×    |  6 ×  6    |
| Indicator | 8 × 8 | 1×    |  8 ×  8    |

### Gotchi sprite palette (save as `gotchi_sprite.gpl`)

| Index | Color      | RGB            | Role                     |
|-------|------------|----------------|--------------------------|
| 0     | `#FF00FF`  | 255, 0, 255    | Transparent (always skip) |
| 1     | `#0000FF`  | 0, 0, 255      | Primary body color        |
| 2     | `#00FFFF`  | 0, 255, 255    | Secondary / highlight     |
| 3     | `#404040`  | 64, 64, 64     | Shadow / dark outline     |
| 4     | `#FFFF00`  | 255, 255, 0    | Accent (eyes, marks)      |

> The converter snaps each pixel to the nearest palette entry by Manhattan distance.
> Use only these 5 colors when painting; avoid anti-aliasing.

### Emote sprite palette (save as `emote.gpl`, use `--emote` flag)

| Index | Color     | RGB           | Role        |
|-------|-----------|---------------|-------------|
| 0     | `#FF00FF` | 255, 0, 255   | Transparent |
| 1     | `#FFFFFF` | 255, 255, 255 | White lines |
| 2     | `#000000` | 0, 0, 0       | Black       |
| 3     | `#FF4040` | 255, 64, 64   | Red accent  |

### Tags (frame ranges, defined in Aseprite's Tags panel)

Each tag becomes a separate group of array constants. Use SCREAMING_SNAKE_CASE.

Common tags:

| Tag name | Use case                     |
|----------|------------------------------|
| `IDLE`   | Default 2-frame loop         |
| `WALK`   | Movement cycle               |
| `EAT`    | Feed action burst            |
| `HATCH`  | Egg crack sequence (4 frames)|
| `REVEAL` | Post-hatch burst             |
| `DIE`    | Death sequence               |

---

## 2. Aseprite Export

**File → Export Sprite Sheet…**

- Layout: Horizontal strip
- Layers: Visible layers
- Output: `art/sprites/<category>/<name>.png`
- JSON data: ✅ enabled — save as `art/sprites/<category>/<name>.json`
  - Meta: Frame tags ✅, Slice keys ☐, Layer names ☐

> The JSON file must be next to the PNG — spr2c.py resolves the PNG path from the JSON.

---

## 3. Run the Converter

```bash
# From project root:
python tools/spr2c.py art/sprites/gotchi/<name>.json

# For emote-palette sprites:
python tools/spr2c.py art/sprites/gotchi/<name>.json --emote

# Custom output dir (optional):
python tools/spr2c.py art/sprites/gotchi/<name>.json src/apps/gotchi/
```

Output: `src/generated/sprites_<name>.h`

Dependencies: `pip install Pillow`

---

## 4. Generated Header Format

```c
// AUTO-GENERATED by tools/spr2c.py — do not edit
// Source: blob_baby.json
#pragma once
#include <stdint.h>

// Palette indices: 0=transparent 1=primary 2=secondary 3=dark 4=accent

// ── blob_baby / IDLE ──────────────────────────────────────────────────────
constexpr uint8_t SPR_BLOB_BABY_IDLE_F0[16*16] = { ... };
constexpr uint8_t SPR_BLOB_BABY_IDLE_F1[16*16] = { ... };

// Sprite size
constexpr uint8_t BLOB_BABY_W = 16;
constexpr uint8_t BLOB_BABY_H = 16;

// Frame counts per tag
constexpr uint8_t BLOB_BABY_IDLE_FRAMES = 2;
```

### Naming rules

| Element     | Pattern                          | Example                        |
|-------------|----------------------------------|--------------------------------|
| Array       | `SPR_{NAME}_{TAG}_F{idx}`       | `SPR_CYBER_ADULT_IDLE_F0`      |
| Width const | `{NAME}_W`                       | `CYBER_ADULT_W`                |
| Height const| `{NAME}_H`                       | `CYBER_ADULT_H`                |
| Frame count | `{NAME}_{TAG}_FRAMES`            | `CYBER_ADULT_IDLE_FRAMES`      |

Where `{NAME}` = JSON filename stem uppercased, `{TAG}` = Aseprite tag name uppercased.

---

## 5. Integrate into Code

1. Place generated header in `src/generated/` (default) or `src/apps/gotchi/` (hand-authored).
2. Include it in the relevant sprite lookup header (e.g. `GotchiAdultSprites.h`).
3. Add a `case` to the lookup function (`gotchiTypeAdultFrame()`, etc.).
4. Build: `pio run` — zero warnings expected for new sprite data.

---

## 6. Quick Checklist

- [ ] Canvas size matches the table above for the target life stage
- [ ] Only palette colors 0-4 used (no anti-alias, no other colors)
- [ ] All animation tags defined in Aseprite Tags panel
- [ ] Exported as PNG + JSON (horizontal strip)
- [ ] `spr2c.py` run from project root — output in `src/generated/`
- [ ] Array name follows `SPR_{NAME}_{TAG}_F{n}` convention
- [ ] Header included in the right lookup `.h` file
- [ ] `pio run` succeeds — no new warnings
